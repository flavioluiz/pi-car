# PiCASSO Product Template

Template de frontend em ingles, quase pronto para integracao, mantido isolado em `experiments/`.

## Objetivo

Simular a estrutura real do produto `PiCASSO` com:

- Home
- Music
- Navigation
- Vehicle
- SDR Radio
- Settings

Com paginas clicaveis, subtabs e layout mais proximo do sistema final.

## Como abrir

Na raiz do projeto:

```bash
python3 -m http.server 8765
```

Abra:

`http://localhost:8765/experiments/frontend-picasso-template/`
